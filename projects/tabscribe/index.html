InputFormatsHow

Editor shortcuts

Click a note, then use the keys. Notes the app is less sure about show in amber.

  • ClickSelect a note
  • ↑ ↓Change pitch
  • 0 to 9Set the fret
  • SMove to another string
  • LLock the fingering
  • Cmd / Ctrl + ZUndo
